# Play Frontend

Child-friendly Next.js frontend for the Bible learning platform.

## Included
- Bright home page with clear entry points for quiz and memory verse play.
- Player setup form wired to the backend API.
- Preview screens for quiz and memory verse flows.

## Environment
- `NEXT_PUBLIC_API_BASE_URL=http://localhost:5000/api`

## Run
Install dependencies, then run:

```bash
npm run dev
```
