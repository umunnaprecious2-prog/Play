```md
This project is a Bible-based educational gaming platform designed to help children become familiar with Scripture through fun, interactive, and engaging games. The initial focus is to build a simple but polished MVP that can be deployed and expanded over time.

The primary audience is children between the ages of 5 and 12 years. Every design and development decision should prioritize simplicity, accessibility, and enjoyment.

The first release will include four core games:

Bible Quiz

Memory Verse Challenge

Who Am I? Bible Character Game

Bible Story Puzzle

The user interface should be designed specifically for children.

Use bright and cheerful colors throughout the application.

Use large buttons and touch-friendly components.

Keep reading to a minimum wherever possible.

Include lots of illustrations and engaging visuals.

Provide encouraging and positive feedback instead of punishment when children answer incorrectly.

The application should include game mechanics that motivate children to continue learning and playing.

Implement XP points.

Implement player levels.

Award stars for good performance.

Include achievement badges.

Provide daily challenges.

Maintain daily learning streaks.

Allow players to unlock avatars as they progress.

The games should have the opportunity to be played again.

Create hundreds of quiz questions.

Randomize answer options each time a question appears.

Support multiple difficulty levels.

Organize content into categories such as Genesis, Exodus, Jesus, Miracles, Prophets, Parables, Kings, Apostles, and more.

Questions, verses, puzzles, and game content should not be hardcoded.

Build an admin dashboard from the beginning to manage all game content.

The admin dashboard should allow administrators to:

Add quiz questions.

Edit existing questions.

Delete questions.

Upload images.

Add and edit Bible verses.

Create, edit, and delete categories.

Manage difficulty levels.

Manage game content for every game mode.

Technology stack

Frontend

Next.js

TypeScript

Tailwind CSS

Backend

Express

TypeScript

Database

PostgreSQL

Prisma ORM

Deployment

Frontend deployed on Vercel.

Backend and PostgreSQL deployed on Railway or Render.

The codebase should be clean, modular, scalable, and easy to maintain. Features should be designed with future expansion in mind, allowing additional games, categories, achievements, and educational content to be added without major architectural changes.
```
